# CHIMERA: Synthetic Health Data Generation with Balanced Fidelity, Utility, and Privacy

This repository contains the code and analysis workflow for the paper **CHIMERA generates synthetic health data with balanced fidelity, utility and privacy** by Amadou Tidiane Niang (University of Lille, France).

CHIMERA is an imputation-based framework for generating fully synthetic tabular health data while jointly addressing statistical fidelity, analytical utility, and privacy protection.

## Overview

CHIMERA extends Multiple Imputation by Chained Equations (MICE) through four main components:

1. **Iterative MCAR masking:** progressively introduces controlled artificial missingness.
2. **Conditional MICE imputation:** reconstructs missing values using variable-specific imputation models.
3. **Mahalanobis-distance realignment:** improves multivariate coherence by aligning synthetic profiles with realistic regions of the data space.
4. **Survival data support:** integrates survival information through Nelson–Aalen cumulative hazard estimation and spline-based reconstruction of survival times.

The framework is evaluated against five alternative synthesis methods using three health datasets and a comprehensive set of fidelity, utility, and privacy metrics.

## Getting Started

### Requirements

The analysis requires R and Python. R scripts attempt to install missing packages where configured to do so; externally generated synthetic datasets require the corresponding Python environments.

### Data preparation

Create the `data/` directory in the project root and place the required input datasets and externally generated synthetic datasets inside it.

| Dataset | Sample size | Data type | Outcome | Availability |
|---|---:|---|---|---|
| PIMA | 768 | Tabular | Diabetes | Public |
| AIDS | 2,139 | Mixed | Survival | Publicly documented |
| REIN | 42,176 | Clinical registry | 90-day mortality | Restricted |

The REIN registry data cannot be redistributed because of privacy and regulatory requirements. Access to these data must be obtained through the appropriate authorization procedures.

### Execution

Run the R scripts sequentially from the project root, following their numerical order. Each script relies on data or results generated by preceding steps.

The main workflow covers preprocessing, synthetic data generation, evaluation, comparative analysis, ablation and sensitivity analyses, and REIN prognostic score validation.

**Note:** CTGAN, TVAE, Gaussian Copula, and TabDiff synthetic datasets are generated externally in Python and imported into the R workflow.

## Benchmark Design

CHIMERA is compared with five alternative synthesis methods across three datasets.

| Component | Description |
|---|---|
| Synthesis methods | CHIMERA, SYNTHPOP, CTGAN, Gaussian Copula, TVAE, and TabDiff |
| Benchmark datasets | PIMA, AIDS, and REIN |
| Replicates | 50 synthetic datasets per method and dataset |
| Statistical settings | Logistic regression for PIMA; Cox regression for AIDS and REIN |
| Evaluation | Fidelity, analytical utility, and privacy |
| Additional analyses | Ablation study, masking-rate sensitivity, and prognostic score validation |

The representative synthetic dataset is selected using a best-of-M procedure based on a composite loss function. The loss combines fidelity, utility, and privacy components with equal weights. Metrics T1–T9 are used for selection, whereas T10–T13 provide additional privacy assessments.

## Evaluation Framework

Thirteen complementary metrics assess the fidelity, analytical utility, and privacy of synthetic datasets.

#### Fidelity

| Metric | Symbol | Description | Optimal value |
|---|---|---|---|
| Jensen–Shannon divergence | T1 — JSD | Marginal distributional differences | → 0 |
| Correlation Frobenius distance | T2 — CFD | Differences in bivariate dependence structures | → 0 |
| Discriminative performance | T3 — DiscPred | AUC of a real-versus-synthetic classifier | → 0.5 |

#### Utility

| Metric | Symbol | Description | Optimal value |
|---|---|---|---|
| Standardized effect difference | T4 — SDiff | Differences in regression effect estimates | → 0 |
| Train on Synthetic, Test on Real | T5 — TSTR | Predictive performance gap between synthetic-trained and real-trained models | → 0 |
| Train on Synthetic and Real, Test on Real | T6 — TSRTR | Predictive performance gap for combined-data and real-data training | → 0 |


#### Privacy

| Metric | Symbol | Description | Optimal value |
|---|---|---|---|
| Record-matching risk | T7 — MIR-RM | Mean Gower distance between real records and their nearest synthetic neighbours | → 1 |
| Holdout membership inference | T8 — MIR-Holdout | Probability that synthetic records are closer to training than holdout records | → 0.5 |
| Attribute inference risk | T9 — AIR | F1 score of a 1-nearest-neighbour attribute reconstruction attack | → 0 |
| Distance to Closest Record | T10 — DCR | Proximity of synthetic records to real records | → 1 |
| Nearest Neighbour Distance Ratio | T11 — NNDR | Relative proximity of the nearest and second-nearest neighbours | → 1 |
| Linkability attack strength | T12 — *s* | Linkability success above the random-matching baseline | → 0 |
| Signed specific linkability risk | T13 — *R* | Normalized excess linkability success in the reference condition relative to control | → 0 |
